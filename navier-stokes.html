What the film means

OpenAI reports a construction for the three-dimensional Navier–Stokes existence and smoothness problem. The flow starts from smooth initial data, with positive viscosity and finite energy, then develops unbounded speed in finite time. The vortex is the intuition: a calm field pulled tighter and tighter until the equations can no longer keep it smooth.

The film is a conceptual explanation. It is not a numerical simulation of real water and it does not claim that a glass of water becomes infinitely fast.

Try the formalisation

The repository README is authoritative for versions and commands. The public setup documented there is:

OFFICIAL REPOSITORY SETUP
git clone https://github.com/openai/NavierStokesAndEuler.git
cd NavierStokesAndEuler
lake exe cache get
lake build

Install Lean with the official Lean installation guide, which uses elan. Then follow the repository’s independent-comparator instructions if you want to check that comparison separately.
