What it is · facts only reflect

Reflect, in three sentences

Reflect is Anthropic's usage dashboard for Claude, in beta since 2026-07-09 — it shows your key topics, usage patterns and task types over 1, 3, 6 or 12 months. It nudges on patterns (turn a repeated task into a Project) and can set quiet hours and break reminders. It's on Free, Pro and Max, requires Memory ON, and excludes incognito and health-connected chats.

The official announcement →
Setup · 4 steps, 2 minutes setup

Set it up

Nothing to install — it's a settings toggle. The only real prerequisite is Memory: with it off, Reflect has nothing to reflect.

01Open Settings → Reflect, on claude.ai or the desktop app.
02Enable Memory if it's off — Reflect reads from it and won't run without it.
03Generate your report and pick the window: 1, 3, 6 or 12 months.
04Optional: set quiet hours and break reminders while you're in there.

10 prompts to audit your AI habits

Reflect shows you the data; these make you face it. Paste your report where a prompt asks for it (copy it from the Reflect screen), or just run them cold — with Memory on, Claude can work from what it already knows about how you use it. Copy, paste, answer honestly.

Prompt 01 · The delegation ledger
Here is my Claude Reflect report: [paste it]. Sort my recurring tasks into three lists: KEEP (I should do these myself — judgment, taste, or skills I'm still building), DELEGATE (mechanical, low-risk, fine to hand off), and STOP (work that shouldn't be happening at all). Then name the one task I currently delegate that I should take back, and say why.
Prompt 02 · The Project finder
From my Reflect report [paste it], list every task type that shows up three or more times. For each one, say whether a Claude Project with standing instructions would beat re-prompting from scratch. Then draft the full Project instructions for the best candidate — context, rules, output format — so I can create it today.
Prompt 03 · The crutch check
Look at what I ask you about repeatedly. Which topics do I keep asking at the same beginner level, month after month — evidence I'm outsourcing instead of learning? Pick the one where learning it myself has the highest payoff, and give me a two-week plan where I do the work and only use you to check it.
Prompt 04 · The quiet-hours draft
My Reflect report shows when I use Claude: [paste the usage-pattern section]. Separate my productive windows from my compulsive ones — the late-night rabbit holes, the procrastination loops. Draft quiet-hours rules I can set in Reflect, plus one honest sentence on what I'm usually avoiding when I open a chat in those hours.
Prompt 05 · The weekly review ritual
Build me a reusable Monday review prompt. It should take this week's Reflect report and last week's, compare them, and make me answer three questions: what did I delegate well, where did I spin, and what will I do differently. It ends with exactly one habit change for the coming week. Output it as a prompt I can save and paste every Monday.
Prompt 06 · The scope-creep scan
Find my chats that started as one small question and turned into hour-long sessions. What do they have in common — topic, time of day, how the first message was phrased? Give me one rule for spotting the drift while it's happening, and one rule for when to close the tab.
Prompt 07 · The verification gap
List my recurring task types and rank them by damage-if-wrong — money, reputation, shipped code, health. For the top three, tell me honestly whether I ever verify your output on them, and give me a five-minute spot-check routine for each one.
Prompt 08 · The prompt tax
Scan my conversations for context I re-type every time — project background, preferences, output formats, constraints. Extract the three biggest repeated blocks, then rewrite each as a standing instruction for a Project or a memory entry, so I never have to type it again.
Prompt 09 · The dependency line
If Claude went offline for a month starting tomorrow, which of my current workflows would break? Rank them by pain. For the top two, describe the backup habit — the manual skill or tool I should keep warm so the dependency stays a choice, not a trap.
Prompt 10 · The honest hour
Read my Reflect report [paste it], then interview me about my AI habits: five hard questions, one at a time, the kind a good coach would ask — no softballs. Push back on my answers. At the end, give me a one-paragraph honest assessment and the single change with the highest payoff.
