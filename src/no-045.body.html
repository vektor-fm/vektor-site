Anthropic published how they actually build software with AI. The interesting part is not the AI — it is the artifact chain. An idea becomes intent.md. That triggers spec.md. That triggers plan.md. That triggers the code. Each handoff is a git commit, so the chain doubles as your audit trail for free. Below: the chain, both guardrail layers, and the one thing AI is never allowed to do.

Fig. 01 ·

The artifact chain.

Every stage produces a file, and that file is what triggers the next stage. Nothing is handed over in a chat window.

Intent → spec → plan → code

intent.md says what we want and why. It triggers spec.md, the testable contract. That triggers plan.md — migration first, then routes. That triggers the diff.

Each of those is committed on its own, before the next one starts.

Four commits instead of one, and the next person never has to ask why.

The audit trail is free

Because each handoff is a commit, git log read bottom-up is the decision history of the feature: who wanted what, what was agreed, how it was going to be done, and what actually shipped.

You do not build the audit trail. You get it because the work happens to be structured this way.

Install it this week

Pick one feature. Before any code, write intent.md and commit it alone. Then spec.md, commit. Then plan.md, commit. Then the code.

The discipline is committing them separately — that is the whole mechanism.

Fig. 02 ·

Skills are advice. Hooks are walls.

These two get used interchangeably. Only one of them stops anything.

Layer 01 — Skills

Company policy, encoded: never touch prod data · cite the file you changed · ask before you spend.

The agent reads them and complies because it was asked to. Which means it can also reason its way around them.

Good for conventions, house style, and what “done” means.

Layer 02 — Hooks

A script that runs before an action and can refuse it. A pre-tool-use hook inspects what is about to happen and exits non-zero.

Nothing talks its way past a non-zero exit. exit 2, the action never ran.

This is the layer that is actually a wall.

Which one to reach for

If the consequence is reversible, a skill is enough. If it is not — production data, spend, deploys, force-pushes — it must be a hook.

Policy is not protection.

Fig. 03 ·

The one thing AI never does.

AI reviews every pull request and can never approve its own code. A human keeps the merge button. Not because the review is worthless — because the control is the approval, not the review. Everything upstream can be agent-driven precisely because this one gate is not.
