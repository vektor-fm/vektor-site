Fig. 02 ·

one at a time, with the traps

1. OmniRoute — never hit the ceiling

One endpoint that fails over to the next provider when your model runs out, so a limit stops being the end of the session. MIT, self-hosted, 53.6k stars. Its README's own numbers: 90+ free tiers, 56 free forever, no card, and “~1.51B Free Tokens / Month” across those documented free tiers.

terminal · install
npx -y omniroute

Also npm install -g omniroute or docker run diegosouzapw/omniroute. Straight about the provider count: we read 349 providers on 23 August 2026 and that is the figure in the film. The README is not internally consistent — its stats block says 342 (v3.8.50) and its headline promise says 351. Same page, three numbers. Take the order of magnitude, not the digit. Repo →

2. claude-mem — stop re-explaining your codebase

Persistent memory across sessions: it holds the project and the files, so a new morning doesn't start with you describing your own repo again. Apache 2.0. Not an Anthropic project.

terminal · install
npx claude-mem install

Or from inside Claude Code:

claude code · marketplace
/plugin marketplace add thedotmack/claude-mem
/plugin install claude-mem

Node.js 20.0.0 or higher is a real prerequisite — it is not auto-installed (Bun, uv and SQLite are). Trap: npm install -g claude-mem gets you the library and none of the behaviour — it doesn't register the hooks or start the worker. Repo →

3. Headroom — send less, get the same answer

Sits in front of the model and compresses your context before it goes out. Apache 2.0, open source, local-first.

terminal · install
pip install "headroom-ai[all]"

What the 77% is: “77% fewer input tokens” is Headroom's own traced example on their own site — not an independent benchmark, and not a promise about your repo. Measure it on your own workload before you count the saving. Site →

4. Claude Code Setup — Anthropic's own

It reads your repo and names the MCP servers, skills, hooks, subagents and slash commands worth adding for your specific stack. Badged “Made by Anthropic” and “Anthropic Verified”, 195,067 installs as of 23 August 2026.

Install from the plugin page itself — it carries an “Install in Claude Code” button rather than a command to paste. It is read-only: it recommends, it never edits your files. If you've seen it described as a tool that “cleans up” or “removes the fluff” from your setup, that's wrong — it changes nothing. Plugin page →

5. Task Observer — your corrections become skills

Captures the corrections you make while working and turns them into skill improvements, so the same correction stops recurring. It's a skill, not a plugin — every skill in that repo is user_invocable, so it's both a /slash-command and something Claude can auto-invoke.

terminal · install
git clone https://github.com/iamneilroberts/claude-skills
cp -r claude-skills/skills/* ~/.claude/skills/

Credit where it's due: skills/task-observer/ is third-party, redistributed unmodified under CC BY 4.0, © Eoghan Henn (rebelytics.com). Repo →

Every quantity on this page and in the film was read from the project's own source on 23 August 2026, and rounded down where we rounded at all. Star counts, install counts and provider counts move — check before you quote us.

What we did not repeat

This film was adapted from a creator's reel that we credit. Three of its claims did not survive our check, so we didn't carry them: it said “1.6 billion free tokens” (the repo says ~1.51B), “over 200 free API providers” (it's 90+ free tiers out of a few hundred total), and that Claude Code Setup “removes the useless fluff” (it's read-only and modifies nothing). We'd rather be the version you can check.
