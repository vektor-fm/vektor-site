One prompt. Bare vs. skilled.

We gave Claude the same one-line prompt twice — "Build a landing page for Orbit, a habit-tracking app" — once bare, once with the three skills loaded. Both artifacts are below, untouched. Open both, judge for yourself.

The honest read: the bare run isn't broken — it's generic. System font stack, the 135° purple-blue gradient hero, uniform cards, two token 0.15s transitions. The skilled run commits: a sans-plus-mono type system with real hierarchy, a palette instead of a gradient wash, and deliberate motion — micro-interactions in the 60–240ms band on custom ease-out curves, with a slow ambient orbit in the background. It's not 10x prettier; it's coherent, like one person made the decisions.
