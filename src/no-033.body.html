the five, in order

Star counts read from the GitHub API on 9 August 2026. They move; the install lines don't.

1. Anthropic's own skills repository

Seventeen example skills, written by Anthropic, sitting in a public repo — document work, design, data analysis, and more. If you have never opened it, this is the fastest upgrade available to you today. 167,145 stars.

git clone https://github.com/anthropics/skills

The seventeen: algorithmic-art, brand-guidelines, canvas-design, claude-api, doc-coauthoring, docx, frontend-design, internal-comms, mcp-builder, pdf, pptx, skill-creator, slack-gif-creator, theme-factory, web-artifacts-builder, webapp-testing, xlsx.

2. The official plugin marketplace

Not a single tool — a curated storefront. Claude Code adds Anthropic's official marketplace the first time you start it interactively, and inclusion in it is at Anthropic's discretion. 33,300 stars.

/plugin marketplace add anthropics/claude-plugins-official
/plugin install github@claude-plugins-official

The community marketplace is a different thing and you add it by hand — third-party plugins that passed automated validation, each pinned to a commit SHA: /plugin marketplace add anthropics/claude-plugins-community. Plenty of write-ups merge the two. They are separate.

3. superpowers

The one that makes Claude work like a disciplined dev team — a full development methodology shipped as skills. It stops Claude jumping straight into code and makes it brainstorm, spec, plan and drive the work through tests, with sub-agents doing and reviewing. 269,521 stars.

/plugin marketplace add obra/superpowers

4. claude-mem

Solves the memory problem. Every session ends and Claude forgets everything. This records what happened, compresses it into summaries, and injects the relevant pieces back into future sessions. 90,145 stars.

npm install -g claude-mem && claude-mem install

5. wshobson/agents

A marketplace for specialised sub-agents — one for reviewing, one for testing, one for architecture. A specialist beats a generalist guessing, every time. 38,638 stars.

/plugin marketplace add wshobson/agents

Fig. 02 ·

rules that actually bite

A markdown file full of laws is a suggestion until something enforces it. These two hooks are what enforce mine. Drop them in .claude/hooks/ and register them in .claude/settings.json.

One: nothing lands on main by accident

A PreToolUse hook on Bash. It reads the command about to run and refuses a commit straight to the trunk before it happens, rather than telling you afterwards.

{
  "hooks": {
    "PreToolUse": [
      { "matcher": "Bash|PowerShell",
        "hooks": [{ "type": "command", "command": "node .claude/hooks/git-flow-guard.mjs" }] }
    ]
  }
}

Two: the design canon rebuilds itself

A PostToolUse hook on Edit and Write. The moment a design token changes, the human-readable board regenerates — so the documentation cannot drift from the source, because nobody has to remember to rebuild it.

{
  "hooks": {
    "PostToolUse": [
      { "matcher": "Edit|Write",
        "hooks": [{ "type": "command", "command": "node .claude/hooks/canon-regen.mjs" }] }
    ]
  }
}

Build your own marketplace

The five above are other people's. The one that changed the most for me was the private one — a marketplace nobody else can see, holding the skills this channel actually runs on. A marketplace is just a repo with a .claude-plugin/marketplace.json in it.

/plugin marketplace add ./my-marketplace
