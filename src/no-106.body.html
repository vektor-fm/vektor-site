The POLISH page · three installs, one order

Look like a designer.

AI-built front ends give themselves away: the same fonts, the same gradients, the same hero. These are the three Claude Code skills from the video that fix most of that, with each install command word for word from its own README (read 2026-11-24), in the order to run them. Taste Skill sets the look, Emil Kowalski's skills add the motion, and Impeccable's /impeccable polish is the last pass before you ship.

Run them in this order: the look first, the motion on top of it, the polish last. Each command is copied from the repo's README on 2026-11-24; the first one listed for each skill is the one the video shows.

1 · Taste Skill: the look

Hands Claude a design opinion before it writes any CSS. In its README's words it deals "a Google Fonts pairing for the page kind" and "one of eleven tested hero layouts". By Leon Lin, MIT licence.

Inside Claude Code, as a plugin:

/plugin marketplace add Leonxlnx/taste-skill
/plugin install taste-skill@taste-skill

Or with the skills CLI, in a terminal:

npx skills add https://github.com/Leonxlnx/taste-skill --skill "design-taste-frontend"

The skill's scripts need Node 22 or newer and an installed Chrome, Edge or Chromium; it needs no API keys. /plugin update upgrades it later.

github.com/Leonxlnx/taste-skill

2 · Emil Kowalski's skills: the motion

Skills for designers and engineers from Emil Kowalski, based, he writes, on his years at companies like Vercel and Linear: animation and interaction rules, so Claude picks easing on purpose instead of leaving a page that never moves. MIT licence. One command:

npx skills@latest add emilkowalski/skills

It is a shell command: run it in a terminal. The video types it inside Claude Code with a leading !, which hands the line to the shell instead of to Claude. Every skill has its own page, with when to use it and prompts to try, at aiforui.dev/skills.

github.com/emilkowalski/skills

3 · Impeccable: the commands, then polish

"The design vocabulary for your coding agent", by Paul Bakaus: commands for type, colour, spacing and layout, plus review commands. Apache-2.0 licence.

Inside Claude Code, add the marketplace, then open /plugin and install Impeccable:

/plugin marketplace add pbakaus/impeccable
/plugin

Or the installer, in a terminal. It detects your coding tools, asks whether to install for this project or globally, and offers a design hook; reload your tool afterwards:

npx impeccable install

Worth knowing from the same README: in Claude Code, installed hooks run even when you deny the model's own commands, so review the hook before unattended runs.

github.com/pbakaus/impeccable · impeccable.style

Before you ship

When the page is built, run the polish pass. The README calls polish "the final pass before shipping": a refinement over the whole interface, not a redesign.

/impeccable polish

Fig. 02 ·

We ran polish on our own page.

On 2026-11-23 we ran /impeccable polish (Impeccable 4.10.0) on the Orbit landing page we built with these skills in July for issue no. 023. A fresh Claude Code agent with no knowledge of the film did the pass the skill describes, no more.

What it changed

Ten changes, all small. The ones you can see: the labels on the orbit diagram went from about 7 to 8 px, unreadable, to readable; on phones the pricing list stopped splitting each bold lead-in and its sentence into two columns; the hero's top spacing started obeying the mobile layout; the smallest legend text matched the text beside it. The rest sit in the code: a keyboard focus ring the page never had, colours moved into the page's own tokens, aligned numerals, bigger footer tap targets, a favicon and a meta description.

What it did not do

It kept the palette, layout, copy and structure. The skill's launcher and detector were not installed, so that part of Impeccable was not run, and the agent checked the page at 1280 and 390 px wide only. The July page itself was made with July versions of the skills; only this polish pass is today's version.

The July test it started from

For no. 023 we gave Claude the same one-line prompt twice, once bare and once with the skills loaded. Both pages are still online, untouched.
