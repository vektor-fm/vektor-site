The Teardown · 008

Strip secrets
from a HAR file.

A browser recording carries your cookies and tokens. Before an AI, a colleague or a git repo sees it, run one script that keeps only the data calls and removes the secrets.

////////////////////////////////////////////////////////////////////////////////////////////////

Fig. 01 ·

what it stops

A HAR file is the recording a browser makes of every request a page sends. It is the first step in the method behind our ENDPOINT film: record a site, hand the recording to Claude Code, get a small client for the data the page loads. The recording is also where the danger sits.

In October 2023 an attacker got into Okta's customer support system and accessed files customers had uploaded with support cases. Okta said some were HAR files containing session tokens that could be used for session hijacking, and that the attacker used them to hijack the sessions of 5 customers. Files tied to 134 customers were accessed.[2] That is the failure this script is aimed at: a recording shared for a good reason, with a live credential inside.

Chrome's own export has a sanitized option, which excludes Cookie, Set-Cookie and Authorization headers.[1] Secrets also travel elsewhere. On the page we recorded, an ArcGIS access token sat inside request URLs, and URLs are not on that list. strip_har.py redacts secret-looking values in URLs, headers, form data and response bodies, and drops everything that is not a data call.

The measured result. On 2026-10-31 we recorded the USGS earthquake map with Playwright driving Chrome: 123 requests, 10,912,685 bytes, a cookie header on 3 requests and the ArcGIS token in URLs. After the script: 39 data calls, 223,753 bytes (48.8 times smaller), no cookie or authorization header, the token string absent, 4 token=REDACTED values. We read these figures from our run notes; the raw file is no longer on disk, so they were not re-measured for this issue. One page, one run.

Some of the saving is a trade. Response bodies are cut to their first 4,000 characters, enough to see the shape of the data and not enough to hold all of it.

Fig. 02 ·

the file

The complete script, 103 lines, Python standard library only. Nothing is sent anywhere. It writes site.clean.har next to the original and prints the data calls it kept.

"""strip_har.py: make a HAR safe and small before any AI (or git) sees it.

    python strip_har.py site.har            -> writes site.clean.har and prints the data calls it kept

What it does (Python standard library only, nothing is sent anywhere):
  - keeps only the data calls: Fetch/XHR requests and JSON responses (drops pages, images, fonts, map tiles,
    and analytics beacons)
  - removes every cookie, Set-Cookie, Authorization and API-key style header
  - replaces secret-looking values (token, key, api_key, auth, session, sig, password...) with REDACTED, in URLs,
    headers (including HTTP/2's :path), form data and response bodies
  - trims each response body to its first 4,000 characters (enough to see the shape of the data)

Chrome's "Export HAR (sanitized)" already drops Cookie, Set-Cookie and Authorization headers, but NOT tokens
inside URLs (the USGS map page itself loads an ArcGIS map style with ?token=... in the URL). Run this anyway.
Still read the clean file before you share it: no filter catches every secret.
From @vektor.fm, free to use and change.
"""
import json
import re
import sys
from urllib.parse import parse_qsl, urlencode, urlsplit, urlunsplit

SECRET_HEADERS = {"cookie", "set-cookie", "authorization", "proxy-authorization", "x-api-key", "api-key",
                  "x-auth-token", "x-csrf-token", "x-xsrf-token", "x-amz-security-token"}
SECRET_NAME = re.compile(r"token|key|secret|passw|auth|session|sig|signature|credential|jwt|bearer", re.I)
BODY_LIMIT = 4000
URL_SECRET = re.compile(r"([?&;](?:[\w.-]*(?:token|key|secret|passw|auth|session|sig)[\w.-]*)=)[^&#\s\"']+", re.I)
BINARY = ("image/", "font/", "audio/", "video/", "application/octet-stream", "application/x-protobuf",
          "application/vnd.mapbox-vector-tile", "application/wasm")
TRACKERS = ("google-analytics.com", "googletagmanager.com", "doubleclick.net", "facebook.com/tr", "segment.io",
            "hotjar.com", "clarity.ms", "sentry.io", "newrelic.com", "nr-data.net")


def scrub(text):
    """Redact secret-looking name=value pairs inside any string (pseudo-headers like :path, referers, bodies)."""
    return URL_SECRET.sub(r"\1REDACTED", text) if isinstance(text, str) else text


def clean_url(url):
    parts = urlsplit(url)
    q = [(k, "REDACTED" if SECRET_NAME.search(k) else v) for k, v in parse_qsl(parts.query, keep_blank_values=True)]
    return urlunsplit(parts._replace(query=urlencode(q, safe=",:/")))


def is_data_call(e):
    kind = (e.get("_resourceType") or "").lower()
    mime = (e.get("response", {}).get("content", {}).get("mimeType") or "").lower()
    url = e["request"]["url"].lower()
    if any(t in url for t in TRACKERS) or mime.startswith(BINARY) or url.endswith(".html") or ".html?" in url:
        return False
    return kind in ("xhr", "fetch") or "json" in mime


def clean_entry(e):
    req, res = e["request"], e["response"]
    req["url"] = clean_url(req["url"])
    for side in (req, res):
        side["headers"] = [{**h, "value": scrub(h["value"])} for h in side.get("headers", [])
                           if h["name"].lower() not in SECRET_HEADERS and not SECRET_NAME.search(h["name"])]
        side["cookies"] = []
    req["queryString"] = [{"name": q["name"], "value": "REDACTED" if SECRET_NAME.search(q["name"]) else q["value"]}
                          for q in req.get("queryString", [])]
    post = req.get("postData")
    if post:
        post["params"] = [{**p, "value": "REDACTED"} if SECRET_NAME.search(p.get("name", "")) else p
                          for p in post.get("params", [])]
        text = post.get("text") or ""
        post["text"] = re.sub(r'("?[\w-]*(?:token|key|secret|passw|auth|session)[\w-]*"?\s*[:=]\s*)("[^"]*"|[^&,}\s]+)',
                              r'\1"REDACTED"', text, flags=re.I)[:BODY_LIMIT]
    content = res.get("content", {})
    content["text"] = scrub(content.get("text"))
    if isinstance(content.get("text"), str) and len(content["text"]) > BODY_LIMIT:
        content["text"] = content["text"][:BODY_LIMIT] + "...[trimmed by strip_har.py]"
    for k in [k for k in e if k.startswith("_") and k != "_resourceType"]:
        del e[k]
    return e


def main():
    if len(sys.argv) != 2:
        sys.exit("usage: python strip_har.py site.har")
    src = sys.argv[1]
    with open(src, encoding="utf-8") as f:
        har = json.load(f)
    entries = har["log"]["entries"]
    kept = [clean_entry(e) for e in entries if is_data_call(e)]
    har["log"]["entries"] = kept
    out = re.sub(r"\.har$", "", src, flags=re.I) + ".clean.har"
    with open(out, "w", encoding="utf-8") as f:
        json.dump(har, f, indent=1)
    print(f"{src}: {len(entries)} requests in, {len(kept)} data calls kept -> {out}")
    seen = {}
    for e in kept:
        u = urlsplit(e["request"]["url"])
        key = (e["request"]["method"], u.netloc + u.path)
        seen[key] = seen.get(key, 0) + 1
    for (method, path), n in sorted(seen.items(), key=lambda kv: kv[0][1]):
        print(f"  {method:6} {path}" + (f"  (x{n})" if n > 1 else ""))
    print("Cookies, auth headers and secret-looking values removed. Read the file once before you share it.")


if __name__ == "__main__":
    main()

Fig. 03 ·

what it cost us before

The first version of this script was wrong in two ways, and we found both only by searching its output. It left the token inside HTTP/2 :path pseudo-headers, so the token was still in the clean file. And it kept 105 entries, because map tiles were typed as fetch requests. Both were fixed and the output re-checked before the run above.

The lesson is the check, not the script: after running it, search the output for a known secret. A filter that looks right is not the same as a file that is clean. No filter catches every secret, including this one; read the clean file once before you share it.

Google published a HAR sanitizer for the same job. Its repository is now archived and read-only, it says it is not an official Google product, and its README says it needs tests.[3] We did not use or test it.

Fig. 04 ·

install in 2 minutes
  1. Record. In Chrome DevTools, go to Network, load the page and do the thing you want data for. Change every filter you care about while recording, so the data call shows each parameter.
  2. Export. Use the sanitized HAR export.[1]
  3. Save the script as strip_har.py and run python strip_har.py site.har.
  4. Check. Search site.clean.har for a token or cookie value you know was in the page. Read the file once.
  5. Hand it over. Give only the clean file to Claude Code, with a prompt that tells it to use only calls present in the recording.

Time: not measured with a person. Our own Claude step on the cleaned file took 48.1 seconds in the 2026-10-31 run.

Fig. 05 ·

what remains untested

One page and one run. We have not tested it on a logged-in site, on pages that put secrets in unusual field names, or on a HAR from another browser. The redaction works by recognising names like token, key, secret, auth, session and signature; a credential under another name passes through. Check a site's terms before pointing any tool at it.
