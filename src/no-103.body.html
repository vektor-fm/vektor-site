Our run on a sample app · 17 November 2026

Quotely is a small proposal tool I built for this test, with the three leaks left in the way a first version usually ships. It has no real users.

I pasted one prompt into Claude Code in its folder. 46 seconds later, on this small app, it had read the code and come back with this report.

This is an excerpt, cut for length, with the formatting marks taken out. The report ends by asking which fixes to apply, and it does not touch a file until it has an answer.

I said yes to all three

It made a branch, wrote the fixes in 3 commits and ran the app's own checks again. Then I signed up in a browser to see for myself.

A second app, a different stack

I ran the same prompt on a second sample app (Python and Flask) to check it was not fitted to the first. It found all three again, and it caught the trap I had left in: that app worked out the trial's end from a setting, so changing 30 to 7 would have cut every current trial short. It stored an end date per user first. Tests went from 7 passing to 28.

Both are sample apps with no real users: the runs show the audit finds the leaks and the fixes work as code.
