Piece 1 · the install npx

One command. Then restart.

npx claude-mem install, then restart Claude Code. That's the whole install. Node.js 20+ is a real prerequisite and is not auto-installed. The installer is interactive — it multi-selects your IDEs and prompts for an LLM provider plus an API key, so don't expect it to run silently. The trap: npm install -g claude-mem installs the SDK/library only — no plugin hooks, no worker service. You'd get the package and none of the behaviour, and nothing would tell you why.

Piece 2 · the hook config hooks

Read the json, not the readme.

Five lifecycle hooks register from the shipped plugin/hooks/hooks.json, plus a Setup version-check pre-hook: SessionStart (matcher startup|clear|compact), UserPromptSubmit, PreToolUse, PostToolUse (matcher *) and Stop. Two things worth knowing. One: PreToolUse fires on Read only — not on every tool call. Two: the repo's own README contradicts its shipped config — it lists SessionEnd, which isn't registered anywhere, and omits PreToolUse, which is. If you're debugging hooks, read hooks.json.

How it works · three moves setup

Capture. Store. Restore.

Capture — the hooks watch the session: tool calls, decisions, file reads. Store — it compresses into a local SQLite database with AI-written summaries, plus a Chroma vector index for hybrid semantic + keyword search. Restore — next session, SessionStart injects the relevant slice back automatically. It runs across 11 hosts: claude-code, cursor, opencode, openclaw, windsurf, codex-cli, copilot-cli, antigravity, goose, roo-code, warp. Not all equal: Copilot CLI is MCP-only — you get search, but not automatic transcript capture. And Gemini is not a host — it's an LLM provider option, in the same slot as OpenRouter.

sqlite + chroma · 11 hosts · verified 2026-07-17 · no gate
