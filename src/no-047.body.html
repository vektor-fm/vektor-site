Install ImageMagick.

One command on Windows, one on a Mac. Everything after this runs offline.

Windows

Press Windows + R, type wt, press Enter to open Windows Terminal. Then:

winget install ImageMagick.ImageMagick

Mac

Open Terminal. If you have Homebrew installed:

brew install imagemagick

What you get

ImageMagick is open source and converts a huge range of image and PDF formats, entirely on your own machine. For video, audio and documents further down you also need ffmpeg and pandoc — install lines are next to each section on the sheet.

Never push a personal document through a random converter off the first page of Google. Keep your files on your machine wherever you can.

Fig. 02 ·

Images and PDFs, one line each.

The pattern never changes: magick <input> <output>. The extensions do the work.

JPG to PDF, live

Copy the file path. In the terminal type magick, paste the path, then the output path, and swap .jpg for .pdf. Enter. Done.

magick photo.jpg photo.pdf

Several JPGs into one PDF

List every input before the output name and ImageMagick stacks them into one file, in order.

magick photo1.jpg photo2.jpg photo3.jpg combined.pdf

PNG to JPG, resize, compress

Same pattern for a straight format swap. Add -resize and -quality flags to shrink a file at the same time.

magick photo.jpg -resize 50% -quality 80 photo-small.jpg

Fig. 03 ·

Video, audio and documents.

Two more tools, same idea. ffmpeg for video and audio, pandoc for documents.

MP4 to GIF, MP4 to MP3

ffmpeg pulls a clip's audio out on its own, or turns the clip itself into a GIF.

ffmpeg -i clip.mp4 -vf "fps=10,scale=320:-1:flags=lanczos" clip.gif

DOCX to Markdown or PDF

pandoc converts a Word document straight to Markdown with no extra install. Going to PDF needs a LaTeX engine installed alongside it (MiKTeX or TinyTeX) — pandoc's own error message names what's missing if you don't have one yet.

pandoc document.docx -o document.md

The honest gaps

PDF to JPG needs Ghostscript installed alongside ImageMagick — not on by default on Windows. HEIC to JPG depends on your ImageMagick build having the HEIC component; if it doesn't, the error tells you which one to look for.

Fig. 04 ·

Let Claude Code write the loop.

Once ImageMagick is installed, Claude Code can drive it and write the batch loop for you.

Say what you want, not the syntax

In a terminal, inside the folder with your files: convert every jpg in this folder to pdf. Claude Code writes and runs the loop.

You do not need to remember loop syntax in any shell — that is the point of asking.

The loop it wrote

On 2026-09-04, asked to batch-convert a folder, it wrote this — bash syntax, the shell Claude Code was running in:

for f in *.jpg; do magick "$f" "${f%.jpg}.pdf"; done

Your files stay yours

ImageMagick did the whole thing locally. Nothing uploaded. No sketchy converter.
