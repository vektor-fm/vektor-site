Fig. 01 ·

Three parts, one state.

The picture in the film follows the same snapshot through these boundaries. Each part has a different job.

1Feed → snapshot. Your adapter normalizes the exchange data. Preserve the instrument, units, prices, waiting orders, sequence and timestamps. Begin with the synthetic file below; no exchange adapter is supplied.
2Snapshot → Jev questions. Send the state with narrowly defined questions and fixed answer options. TypeSafe documents independent evaluation against the same state; the sample request is an unvalidated prompt experiment, not a recorded API result.
3Answers → your code. Your application applies its quote policy and account limits, then proposes a cancel, submit or no-action decision. Inspect those proposals in replay or paper mode before considering any exchange integration.
