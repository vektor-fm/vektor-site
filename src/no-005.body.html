Rule 01 / 04 · the honesty test mode

Know your mode

Ship mode: it just has to exist. Learn mode: you leave better than you arrived. The honesty test: if you couldn't rebuild it without AI afterwards, you didn't learn it — you shipped it. Both are fine. Lying to yourself isn't.

Rule 02 / 04 · flip the tool why

Ask why. Not do.

When you're learning, flip the tool: write the code yourself — docs, not copy-paste — then bring it to the AI and ask why it didn't work. "Why" teaches; "do it for me" doesn't.

Rule 03 / 04 · source of truth brain

Give your project a brain

One markdown file, the source of truth. Every new AI chat starts by reading it: the model stops guessing, and writing it keeps YOU honest — if you can't explain a decision, you never had a reason. Template below.

Rule 04 / 04 · the whole game taste

Steal taste

Read code by better engineers: strict open-source repos, merged PRs, and especially REJECTED PRs — working code a maintainer said no to, with the why written down. The no is the lesson.

Books: The Pragmatic Programmer · A Philosophy of Software Design (Ousterhout).
