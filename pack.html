Everything from NO. 004 in one place: the five skills, what each one actually does, and the exact install line — verified against each repo, not guessed. Paste them into a terminal (or Claude Code itself for the /plugin ones) and you're set.

01Find Skills

The package manager for skills — searches the library and installs what you need. The one that finds the other four.

npx skills find <what you need>
npx skills add vercel-labs/agent-skills -a claude-code
github.com/vercel-labs/skills

02Superpowers

Makes Claude plan properly and check its own work before it calls a task done. Run inside Claude Code:

/plugin install superpowers@claude-plugins-official
github.com/obra/superpowers

03Claude-Mem

Cross-session memory — it remembers your project so you stop re-explaining it every time.

npx claude-mem install
github.com/thedotmack/claude-mem

04Impeccable

Front-end design taste on tap — kills AI-slop UI before it reaches your screen. The installer detects your setup and asks project vs global.

npx impeccable install
github.com/pbakaus/impeccable

05Task Observer

Watches how you work and quietly improves your other skills over time. The last one runs itself.

npx -y skills add rebelytics/one-skill-to-rule-them-all --skill task-observer --agent claude-code
crossaitools.com/…/task-observer

+Starter settings

Drop this in .claude/settings.json at your project root. It pre-approves the read-only commands Claude asks about constantly, so the skills above run with fewer permission prompts — without approving anything that writes.

{
  "permissions": {
    "allow": [
      "Bash(git status)",
      "Bash(git diff:*)",
      "Bash(git log:*)",
      "Bash(npm run lint)",
      "Bash(npm run test:*)"
    ]
  }
}

Two habits that outdo any config: keep a short CLAUDE.md at the repo root (what the project is, how to run tests, what "done" means) — every skill reads it. And let claude-mem do the remembering instead of pasting context every session.
