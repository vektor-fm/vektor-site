GB200 NVL72 · One Prompt, Two Models
GPT-6 Pro vs Fable 5.1 · one prompt · no follow-ups

Not AGI,
but it built the rack.

GPT-6 Pro in ChatGPT and Fable 5.1 in Claude Code got the same prompt and a clock: build an interactive exploded three.js diagram of NVIDIA's GB200 NVL72 rack, no follow-up messages allowed.

See both racks ↓ Read the exact prompt → Cast your vote →
////////////////////////////////////////////////////////////////////////////////////////////////

Fig. 01 ·

The verdict.

Both models came back with a rack that explodes, orbits and names its parts on click, and both got the hardware counts right against NVIDIA's own numbers: eighteen compute trays, thirty-six Grace CPUs, seventy-two Blackwell GPUs. That is genuinely useful: a working, clickable teaching tool built from one sentence, in under fifteen minutes each. It is also, in places, embarrassing. Drag Fable's slider to the end and the Grace CPU label lands on top of the Blackwell GPU label. Turn a phone upright and Fable's exploded rack falls off the left edge. Click around ChatGPT's rack and three of five scripted clicks land on empty space. None of that is evidence of general intelligence. It is evidence of a good demo, which is a different thing, and that is the whole verdict: break both files yourself below, then pick a side.

Fig. 03 ·

The exact prompt.

One message, no follow-ups, sent to both. Nothing added afterward to either model.

PROMPT.txt
Build an interactive exploded-view 3D diagram of an NVIDIA GB200 NVL72 rack (Grace Blackwell) in three.js, as a single self-contained index.html that loads three.js from a CDN. Requirements: the rack's main parts modelled as simple 3D geometry and labelled (compute trays with Grace CPUs and Blackwell GPUs, NVLink switch trays, power shelves, the NVLink spine and cabling, liquid-cooling manifolds, the rack frame); an explode/assemble slider that spreads the parts apart along sensible axes; an orbit camera; click any part to show its name and a one-line description. Make it look premium. Return only the complete file.

SHA-256 of this prompt, both runs (EVALUATION.md): 3ad96c0abdab9c461474be08f0b6398a29745630cbc0f888fb752f36d901ef0d

Fig. 04 ·

How the clock ran.

Same harness, same steps, run separately against each file, quoted from EVALUATION.md: "headless Chrome 145.0.7632.77 via global puppeteer, SwiftShader WebGL, desktop viewport 1440x900 then portrait 1080x1920, identical scripted actions, screenshots under 2000 px, visual reading by an Explore sub-agent."

549.8sFable 5.1 in Claude Code. Process wall-clock, start to exit, including CLI start-up and transport. This tool has no isolated generation timer. Source: EVALUATION.md.
856s ±10sGPT-6 Pro in ChatGPT. Per ChatGPT's own on-screen badge ("Worked for 14m 16s"), including its web searches and sandbox steps. Source: EVALUATION.md.
"Elapsed (different products, different tooling: NOT a model race)", EVALUATION.md's own side-by-side table, verbatim. Different tools, different environments, different amounts of agentic work: Astra ran web searches and a code sandbox, Fable had no tools at all. The clock is on the page because the prompt said "a clock to check," not because either number proves which model is faster or smarter.

Fig. 05 ·

What broke.

Every defect below is reproducible in the live racks above. Quoted from EVALUATION.md's sub-agent visual reading, same seven scripted questions asked of both files.

Fable 5.1: files/no-050/fable-gb200-nvl72.html

Drag the explode slider to the end: "Grace CPU ×36" sits on top of "Blackwell GPU ×72", and the "NVLink switch tray ×9" label clips against the left panel edge. Reproducible every time. EVALUATION.md, files 03 and 09 through 12.

Fable 5.1: same file, portrait 1080x1920

Turn the viewport to portrait and explode past roughly 70 percent: the rack's geometry cuts off at the left edge, and the NVLink spine and DC busbar labels truncate at the right edge. Desktop is unaffected. EVALUATION.md, files 14 and 15.

GPT-6 Pro: files/no-050/gpt6-gb200-nvl72.html

Three of five scripted desktop clicks land on empty space and leave the default system panel up. It's a layout consequence, not a broken click handler. The exploded rack sits in a narrow canvas column rather than filling the viewport, and the two hits that do land (plus the one portrait click tested) all behave correctly. EVALUATION.md, files 08, 09 and 11.
